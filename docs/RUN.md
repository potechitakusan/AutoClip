### 事前準備（ユーザー/AIエージェントの操作）
1. **素材の用意**: 画像フォルダーと空ページを持つCMCを用意し、プロジェクトの `input` フォルダーへ置きます。
   - 配置例: `input\画像\`（画像フォルダー）、`input\作品\作品.cmc`（CMC）。
   - `input` の中身は原本として変更されません。処理は `work` 内の作業コピーで行います。
   - CMCのページ数は画像数以上である必要があります。
   - 画像の自然順でページに対応します。
2. **CLIP STUDIO PAINT EX の配置**: WindowsのクリスタEXをメイン画面で最大化します（基準1920×1080・100%、複数画面環境の場合は主画面）。
3. **操作の制限**: GUI処理中はキーボードとマウスに触れないでください。

### 実行コマンド（ユーザー/AIエージェントの操作）
プロジェクトルートから実行します：

```powershell
autoclip.cmd run input\画像 --cmc input\作品\作品.cmc --job 作業名 --upscale none
```

### 試運転（新しい作業の初回は1ページ目だけ）
- 新しい作業の最初の `run` は、**1ページ目だけ**を処理して止まります。校正の誤りを、全ページを使う前に見つけるためです。
- 止まるときに `output/<作業名>/trial.png` を出力します。左が検出した枠（元画像）、右が描画後・保存前のクリスタ上の用紙です。
- 枠の数・位置・形と、画像の収まりを見て問題がなければ、`autoclip.cmd run --job 作業名` で残りを処理します。2回目以降は試運転になりません。
- 問題があるときは続行せず、校正を直して**新しい作業名**でやり直します（完了印・バックアップは削除しません）。
- `--all` を付けると試運転を省いて全ページを処理します。`--page N`・`--dry-run` も試運転になりません。完了済みのページがある作業も、試運転になりません。1ページ目が失敗した場合は、次の `run` も試運転のままです。
- 試運転の確認はAIエージェントが画像を見て行います（手順は AGENTS.md）。

### 基本動作（自動処理）
- 作業コピー、検出、計画、コマ画像配置、投入、保存後確認を一括処理します。
- 描画の前に、認識した用紙領域の縦横比をCLIPの用紙寸法と照合します。合わなければ「用紙領域の縦横比が合いません」と表示して安全停止し、完了記録は作りません。タブは閉じて作業コピーをバックアップへ戻します。
- 「成功」は保存ファイルの構造確認の合格を表し、見た目の正しさまでは保証しません。
- 既定（`--fit cover`）は、元画像の縦横比を変えずに全体を同じ倍率で拡大し、基本枠を隙間なく埋めます。縦横比が元画像と用紙で違うと、基本枠からはみ出す部分は隠れます（枠は基本枠で切り、はみ出し分は作りません。10%以上隠れる場合だけ警告）。
- 縦横を別々に基本枠へ合わせる従来方式（画像が伸び縮みします）は `--fit stretch` です。
- コマ外接矩形に12px＋画面粒度ぶんの余白を付けた透明PNGを配置します。
- 多角形はCSPの枠でクリップします。
- コマ外の独立レイヤーは作成しません。

### オプション一覧

| 指定 | 動作 |
|---|---|
| `--upscale none` | LANCZOSの通常拡縮。必要倍率が1.25倍を超えるコマは「画質が低下します」と警告して続行 |
| `--upscale builtin --model モデル.safetensors` | 既存の組み込み `.venv/Scripts/python.exe` で`scripts/upscale_runner.py`を実行 |
| `--upscale external --python 指定先\python.exe --model 指定先\モデル.safetensors` | 指定Pythonを `-B -s` で読み取り利用。探索・インストール・外部環境の変更はしない |
| `--long-edge auto` | 既定値。必要倍率1.25倍以下ならモデルを使わず、それ以上は必要サイズへ拡大。x4・長辺16384pxを上限にする |
| `--frames-only` | 空のネイティブコマ枠だけを作成。コマ画像・モデルは不要 |
| `--fit cover\|stretch` | 既定 `cover`=縦横比を保って基本枠を埋め、はみ出しは隠す。`stretch`=縦横を別々に合わせる。job.jsonに保存され、変更には新しい作業名が必要 |
| `--all` | 試運転（1ページ目だけ）を省いて全ページを処理 |
| `--tolerance small\|medium\|large\|ignore` | 用紙領域の縦横比の許容誤差。small=0.5%、medium=1.5%（既定）、large=5%、ignore=検査しない。いずれも画面の1px丸めを加味。job.jsonに保存され、`run --job 名` で再利用 |
| `--page N` | 1始まりの指定ページだけ処理 |
| `--dry-run` | GUI・推論なし。作業コピー・解析・計画・確認画像まで |
| `--review` | 投入前にHTMLを開き、本人が「はい」を選んだときだけ投入。「いいえ」が既定で取消時は投入しない |

### 拡大（AIアップスケール）の詳細仕様

#### 自動処理
- **モデル仕様**: builtin/externalはRealESRGAN x4 RRDBNetのsafetensors・CUDA・fp32・tile256/pad32を使用します。
- **倍率計算**: コマのcanvas寸法÷ソース寸法の縦横の大きい方となります。
- **出力処理**: モデル出力はLANCZOSで配置サイズへ拡縮します。
- **エラー処理**: 拡大失敗はそのページだけスキップし、他のページを続行します。指定パスが不正でも別環境へ自動で切り替えることはしません。

#### ユーザー/AIエージェントの操作
- 依存関係とモデルはあらかじめ用意してください。

---

### 確認レビューと設定保存
- **確認の有無**: 確認は既定でなしです。
- **レビュー操作（ユーザー本人の操作）**: `--review` の回答はユーザー本人が行います。確認画像と警告は `output/<名>/index.html` に出力されます。
- **設定の再利用（自動処理）**: 設定はjob.jsonへ保存され、`run --job 名` で再利用します。

---

### GUIエラー時の安全停止・復元処理（自動処理）
- **失敗時の自動再試行**: GUIのページ失敗時はタブを閉じ、保存確認が出れば「保存しない」を選択 → バックアップ復元 → 1回再試行します。
- **スキップ判定**: 2回失敗したページは復元してスキップします。
- **保存判定**: 保存はファイルのmtime/size変化を最大30秒待ちます。
- **安全停止時の画面保護**: 汎用OSタイトルではタブ名照合を行わないため、他作品のタブを切り替えないようにしてください。別プロセス・識別できる別タブ・古い校正などの安全停止では画面を残します。

---

### 完了時の動作と引き渡し案内

#### 自動処理
- 完了時は「成功 n / スキップ m」と理由が表示され、クリスタが最小化されます。
- `.done` と保存ファイルのハッシュが一致するページは、再実行時に自動でスキップします。

#### 案内・対応方法（ユーザー/AIエージェントの操作）
- 案内先は出力の **作業用CMCの実際のパス**（`work/<名>/project/`）です。
- CMCと全ページCLIPを含む管理フォルダー全体を渡してください。

---

### 状態確認と再実行（ユーザー/AIエージェントの操作）

状態の確認や再実行は以下のコマンドで行います：

```powershell
autoclip.cmd status --job 作業名
autoclip.cmd run --job 作業名
```

#### 失敗時のトラブルシューティング
- 表示された日本語1行の原因を直して再実行します。
- 1ページだけ処理する場合は `run --job 作業名 --page N` を使用します。
- 対象の作業タブが残った安全停止では、ユーザーが保存せず閉じてから再実行してください。
- 解像度・DPI倍率・テーマ・言語変更時は再校正が必要です。
- 原本・バックアップ・完了印は編集しないでください。
- 対象・画像あり／枠のみ・拡大方式・配置方式（`--fit`）を変更する場合は、新しい作業名を使用してください。
