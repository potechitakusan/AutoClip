中断時次の操作

中断したとき

state（work\作業名\state\）やoperationsを削除して再投入しないでください。完了済みページは、同じコマンドの再実行で検証だけされてスキップされます。最初に、AIエージェントに「状態を確認して」と伝えるか、次を実行します。

.\autoclip.cmd status

1行目に作業の状況、最後の行に次の操作が出ます。止まった理由は work\作業名\last-error.json と、そこに書かれたログにあります。

症状確認・復旧
前面がクリスタでない／画面を触ってしまった処理は安全のため止まります。クリスタのダイアログを閉じ、メイン画面で最大化し、同じコマンドを再実行します。
「画面・DPI・用紙の位置が違う」画面設定を校正時に戻すか、校正をやり直します。許容値だけを緩めて進めません。
投入中に止まったページがあるstatus に「interrupted」と出ます。ディスク上の保存状態と、クリスタに残った未保存タブの両方を確認します。保存前なら、そのタブを保存せずに閉じ、AIエージェントに再実行を依頼します。保存済みか分からない時は、作業フォルダー全体を別の場所へコピーしてから、AIエージェントに相談してください。
基本枠のコピー中に止まったwork\作業名\template\seed.json と backups\before-template-copy\ を保管します。元のページは退避先に残っています。自動では上書きしません。
拡大が止まった同じ run upscale を再実行します。完成した画像は検証して再利用されます。GPUのメモリ不足は自動でタイルを小さくします。
完了通知が見えないwork\作業名\import-status.html を開きます。Windowsが通知を抑制している場合があります。

最初からやり直したいとき

別の作業名で configure し直します（work\ と output\ の既存の作業は残ります）。input\ の原本は変更されていません。

次に行う操作

AIエージェントに「状態を確認して」と伝えるか、.utoclip.cmd status を実行してください。

案内の順序：現在の状態 → 開始前の準備 → 実行手順 → 完了の合図 → 中断時 → 次の操作。
