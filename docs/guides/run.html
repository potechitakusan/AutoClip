全体の流れ

AIエージェントが次の順に進めます。ページ数が増えても、あなたが行う操作は変わりません。

設定後は1回のコマンドで実行する

.\autoclip.cmd run all

確認者名は「ユーザー」が自動で使われるため、名前の入力や毎回の質問はありません。別の名前を使いたい場合だけ --reviewer "名前" を指定します。解析結果を確認する操作は必要です。

作業設定とComputer Useによる画面確認・校正が済んだ状態で実行します。基本枠の準備・解析を順に行い、解析結果HTMLを開きます。全ページと警告ページを確認した後、確認ダイアログで「はい」を押してください。そこから拡大・投入・保存・階層検査まで続きます。「いいえ」は移送を始めず停止します。確認をAIが代行することはありません。すでに承認済みの結果は確認ダイアログを省略します。

未校正の場合は AGENT_CALIBRATION_REQUIRED と表示して停止します。エージェントが PROFILE.html のComputer Use方式で画面を見て校正し、同じ一括コマンドで再開します。画質低下の未了承なども停止します。完成済みページの記録は削除しないでください。GUI処理中は画面に触れず、途中の解析結果確認中だけ操作します。

段階内容あなたの操作
1. 質問縦横比・拡大・画面について、最初にまとめて質問します。答える
2. 校正Computer Useで画面を操作して座標をまとめて登録し、自動検証（PROFILE.html）。F8不要。画面に触れず待つ
3. 基本枠の準備1ページ目に基本枠を作り、全ページへ配布します。画面に触れない
4. 解析全ページのコマを自動検出します（画像は読み込みません）。なし
5. 確認output\作業名\index.html を開き、各ページの「左右比較」と「基本枠への配置見本」で、コマの境界・読み順・コマ外の文字を確認します。「要確認」のページは特に見てください。確認して、AIに「確認した」と伝える
6. 拡大選んだ方法でコマ画像を拡大（または元画像をそのまま使用）します。なし
7. 投入クリスタで各ページに枠を分割し、画像を入れて保存します。1ページ約30秒です。画面に触れない

確認で直したいとき

コマの追加・削除・座標・読み順は、AIエージェントに「ページ○のコマ△を直したい」と伝えれば、補正ファイルを作って適用します。補正するとそのページの確認は無効になるので、もう一度確認してください。

配置の仕組み

元のコマ群全体を、クリスタの基本枠いっぱいに写します。縦と横の比率を別々に合わせるため、元の縦横比と基本枠が違うと、画像がその分だけ縦または横に伸び縮みします（「基本枠への配置見本」で確認できます）。余白を許して縦横比を保つ配置は、まだ使えません。コマ外のタイトルなどは、元の位置のまま別レイヤーに残ります。

完了の合図

投入が全ページ成功すると、クリスタが最小化され、AIエージェントのウィンドウに戻り、通知が出ます。結果は work\作業名\import-status.html にも残ります。完了通知・コマンド出力に表示された保存先の作業用CMCをクリスタで開いて各ページを確認してください。保存先は work\作業名\project\作品名.cmc です。input 内のCMCは変更していない原本なので、移送結果は反映されません。作品を移動・共有する場合は、CMCと各ページのCLIPが入った管理フォルダー全体を扱ってください。
