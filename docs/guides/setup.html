1. 必要なもの

項目内容
OS・アプリWindows 10/11、CLIP STUDIO PAINT EX（日本語UI）。メニューの操作キー（Alt+L→E→C など）は日本語UIで確認しています。
PythonPython 3.12 と uv。
GPU（任意）NVIDIA GPU があるとAI拡大が速くなります。無くても動きます（CPU）。

2. 既存環境の有無と、検索してよいかをユーザーに聞く

AIエージェントは最初に「ComfyUI / StabilityMatrixなどの画像生成環境はありますか。ある場合、AIがPythonとモデルを探してよいですか」と尋ねます。環境があると答えただけでは検索を始めません。検索してよいという明示的な回答を得てから調べます。検索を希望しない場合は、利用するPythonとモデルのパスを直接指定できます。回答待ちの間も外部環境を探しません。

既存環境は読み取り専用で利用します。外部環境へパッケージを追加したり、設定を変えたりしません。AutoClip用のtorchを重ねて導入する必要はありません。

まずPowerShellをこのフォルダーで開き、解析・操作用の .venv-tools だけを作ります。既存環境を使う場合も、拡大しない場合も、この共通の準備だけで進められます。

.\scripts\setup.ps1
# 入力作品だけを調べる（外部環境は検索しない）
.\autoclip.cmd scan

通常のセットアップでは .venv（AI拡大用）もtorchも導入しません。既存環境の検索を了承した場合だけ、エージェントが次を実行します。

.\autoclip.cmd scan --discover-env
# 場所を指定して探す場合も、ユーザーに検索範囲を確認してから実行
.\autoclip.cmd scan --discover-env --search "既存環境のフォルダー"

検索を断った場合・回答が不明な場合は検索しません。指定されたPythonとモデルを利用する場合は、指定先だけの依存関係と対応可否を確認します。依存関係が足りない場合は別の利用可能な環境か、次の新規導入・拡大なしを選びます。

3. 拡大方法を選ぶ（新規導入は選択後だけ）

方法手順
A. 既存のComfyUI / StabilityMatrixを使う（有無をユーザーに質問）ユーザーが直接指定したPythonとモデル、または検索の了承後に scan --discover-env で見つかった候補を選びます。AutoClipのAI拡大用環境の新規導入と fetch-model は不要です。使えるのは .safetensors 形式のRRDBNet（x4）モデルです。
B. 組み込みのAI拡大環境を新規導入する既存環境を使わず、AutoClip専用の拡大環境を作ると選んだ場合だけ実行します。
.\scripts\setup.ps1 -BuiltinUpscale
# GPUが無い、または使わない場合は上の代わりに実行
.\scripts\setup.ps1 -BuiltinUpscale -CpuOnly
# 環境を作成してからモデルを取得
.\autoclip.cmd fetch-model
.venv にtorchと拡大用の依存関係を導入します。公式の RealESRGAN x4plus を取得し、ハッシュを確認してから models\RealESRGAN_x4plus.safetensors に変換します。モデルは約70MBです。CPUだけで拡大する場合は、作業設定の upscale.device を cpu にします（AIエージェントが設定します）。
C. 拡大しないモデルは不要です。コマを大きく引き伸ばす場合は画質（鮮明さ）が落ちます。必要な倍率を計算し、1.25倍を超える場合は、許容するかを確認します。

4. 漫画画像と、クリスタEXの空の作品を用意する

移送先は、まだ絵を描いていない空の複数ページ作品で大丈夫です。漫画画像をクリスタへ手動で貼ったり、コマ枠を描いたりする必要はありません。ここでは用紙・基本枠・ページ数を決めた空の作品を、CLIP STUDIO PAINT EXで作ります。

4-1. AIが生成した漫画画像を置く

input\ の下に作品のフォルダーを作り、PNG/JPGを読みたいページ順に並ぶ名前で置きます。例：input\作品\images\page-001.png、page-002.png。画像の枚数を数えておきます。

4-2. CLIP STUDIO PAINT EXで空の複数ページ作品を作る

  1. CLIP STUDIO PAINT EXを起動し、［ファイル］→［新規］を開きます。
  2. ［作品の用途］で［コミック］を選びます。必要な項目が見当たらない場合は［すべてのコミック設定を表示］を選びます。
  3. 用紙サイズと解像度を設定し、漫画原稿の基本枠も設定します。この基本枠の内側へ漫画を配置します。迷う場合は希望する仕上がりサイズをAIエージェントに伝えてください。用紙や基本枠を後から変更すると、画面の校正をやり直す必要があります。
  4. ［複数ページ］をオンにし、［ページ数］を漫画画像の枚数以上にします。例：画像が8枚なら8ページ以上です。最初は本文だけの作品として［表紙］をオフにし、ページは1枚ずつ独立させます（見開きのページは作りません）。綴じる方向は読みたい向きに合わせます。
  5. 作品名を入力し、［保存先］の［参照］から input\作品\ を指定します。その中に、クリスタが作品を管理するフォルダーを作ります。
  6. ［OK］を押します。空のページが並ぶページ管理ウィンドウが表示されれば、作品が作成できています。この新規作成で、管理ファイル .cmc と各ページの .clip が自動で作られます。自分で空のファイルを作ったり、拡張子を変えたりする必要はありません。

この作成操作の画面例は、セルシス公式：複数ページ作品を新規作成するを参照してください。

4-3. 作成できたことを確認する

エクスプローラーで、指定した保存先の中にできた作品の管理フォルダーを開きます。作品名.cmc と page0001.clip、page0002.clip などが一緒に入っていれば準備完了です。.cmc は作品全体の管理用、.clip はページごとのファイルです（公式：管理ファイル・ページファイルについて）。

別の場所で作品を作った場合は、管理フォルダーを丸ごと input\作品\ の下へコピーしてください。.cmc だけを移さず、各ページの .clip との配置とファイル名を保ちます。画像フォルダーとクリスタ作品の管理フォルダーは別々で構いません。

ページ数が足りない場合は、クリスタのページ管理ウィンドウでページを選び、［ページ管理］→［ページの追加］で増やします。準備できたら、AIエージェントに画像の場所と作成した .cmc の場所を伝えてください。以後、AutoClipは input\ を原本として保持し、work\ に作品を複製してコマ枠の作成と画像の移送を行います。

5. クリスタの設定

  • 環境設定の「定規・単位」の長さの単位を px にします。
  • コマ枠の線の色は黒、他の作品やドキュメントは開いたままで構いません（このツールは対象の作業コピーだけを開閉します）。

続きは AIエージェントに「漫画を移送したい」と伝えれば、質問しながら進めます。画面の校正は PROFILE.html です。
