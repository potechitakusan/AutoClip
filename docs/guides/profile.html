画面の校正（プロファイルの記録）

Computer Useを使い、AIエージェントがクリスタの画面を見て校正します。同じデスクトップ接続で画面取得・クリック・入力を続け、観測した操作位置をまとめて登録します。F8は不要です。固定パレット配置との一致も要求しません。

最初に、エージェントがローカルWindowsのクリスタを実際に撮影・操作できる接続か確認します。ブラウザー専用の接続や別のクラウドデスクトップでは、このクリスタを操作できません。接続できない場合は説明して停止し、代替方式を使うか確認します。

許可の回数はComputer Use側の承認設定に依存します。部品ごとのシェル実行を減らす構成ですが、許可が不要になる保証はありません。

次の場合は、記録し直します：画面の解像度・倍率・枚数・位置を変えた、クリスタのバージョンやパレット配置を変えた、用紙サイズを変えた、実行時に「画面・DPI・ツール設定が違う」と止まった。

始める前に（クリスタ側）

  1. 上の「ディスプレイとクリスタを揃える」を確認します。クリスタは1つだけ起動し、メイン画面で最大化します。
  2. 「ツール」パレットでコマ枠ツールを選び、サブツールパレットで「コマ枠カット」の「コマフォルダー分割」を選びます。
  3. ツールプロパティで、分割形状＝直線、分割方法＝空のフォルダーを作成にし、「環境設定の枠線間隔」のチェックを外します（「左右の間隔」「上下の間隔」の欄が表示されます）。
  4. ツール・サブツール・ツールプロパティ・レイヤーの各パレットを表示します。レイヤーパレットは右側に置き、4〜5行が見える高さにします。
  5. 環境設定で長さの単位が px になっていることを確認します（SETUP.html）。

Computer Useでの校正（標準）

エージェントは準備コマンドを実行し、練習用ページをComputer Useで開きます。現在の画面からボタン・入力欄・ツールの位置を調べ、練習用の空のコマ枠を作ります。観測した座標はまとめて登録します。途中で画面が変わったら、必ず新しい画面を確認します。

位置を調べ終えたら、検証コマンドを1回実行し、色見本の4コマを分割・充填・保存して検査します。検査に合格した場合だけ移送に使います。この間はキーボードとマウスに触れず待ってください。解析結果の確認ダイアログが出た時は、ユーザー本人が確認してください。

代替の校正（Computer Useが使えず、ユーザーが了承した場合）

エージェントが profile agent を使い、校正用画像を段階ごとに見ながら座標を登録します。実行環境によっては、操作ごとに許可が必要になります。Computer Useからこの方式へ勝手に切り替えることはありません。

手動記録（ユーザーが希望した場合だけ）

AIエージェントが profile record を実行すると、クリスタが前面に出て、練習用のコピーが自動で開きます。画面下に黒い案内ボックスが出るので、次を繰り返します（全部で12項目）。

  1. 案内に書かれたボタンやパレットの上にマウスを置きます（クリックしない）。
  2. キーボードの F8 を押します。F8 はクリスタには届きません。位置が記録され、次の案内に変わります。

項目の例：「コマ枠フォルダー」ダイアログの線の幅の欄と OK ボタン、レイヤーパレットの1行目・2行目と展開矢印、コマ枠ツールのアイコン、サブツールの2つの項目、ツールプロパティの2つの間隔欄、メニューの「画像」。OKボタンは押さずに、位置だけを指してください。途中でメニューやダイアログが自動で開閉します。

練習用のコピーは work\作業名\profile\ にあり、元の作品には影響しません。他のドキュメントの保存・終了も行いません。

自動の確認

記録のあと、同じコピーの上で色見本の4コマを実際に分割・充填・保存し、枠の位置・線の太さ・レイヤーの構造を検査します。合格するとプロファイルが「検証済み」になり、解析へ進めます。不合格の場合は理由が表示されるので、その内容に従って記録し直します。

止まったとき

症状対処
「用紙全体が画面に見えない」クリスタで「表示 → 全体表示」にして、用紙がすべて見える状態にします（スクロール・回転をしない）。
「線の幅が違う」環境設定の長さの単位が px か確認し、記録し直します。
「ツール設定が変わった」コマフォルダー分割の設定（直線・空のフォルダー・間隔の欄）を確認します。
案内ボックスが出ない表示の準備が15秒以内に完了しなければ、F8待ちに入らず停止します。原因は work\作業名\profile\teach.window.log に記録されます。AIエージェントに停止理由を伝えてください。
エージェントがボタンや入力欄を識別できないエージェントが現在のスクリーンショットを見たか確認してください。必要なパレットが隠れている場合は表示します。画面画像を取得・閲覧できない環境では、この校正方式は使えません。
校正中にChatGPTの許可画面などへ切り替わった許可操作を終えると、対象のクリスタを前面に戻してから練習用ページを確認します。復帰に時間がかかる場合は最大5回まで再試行します。復帰できず停止した場合は、エージェントが profile agent --step capture で同じ段階の画面を撮り直して再開します。記録を消したり、最初からやり直したりする必要はありません。
OSから練習用ページ名を取得できないエージェントが直近の校正画像で、練習用のアクティブタブの名前と選択状態を確認し、そのタブ領域を補助確認用に登録します。同じプロセス・ウィンドウ・画面設定とタブ画像が一致する場合だけ続行します。別作品名が取得された場合や画像が変わった場合は停止します。この補助確認は、任意のタブを自動認識する機能ではありません。
途中でクリスタに未保存の練習用ページが残った名前が record または verify のタブは練習用です。保存せずに閉じて構いません。
