# AutoClip v2 初回校正（AIエージェント用・1ページ）

実機でFrameOnly 6/6・manga 4/4を完走した手順です。ローカルWindowsのCLIP STUDIO PAINT EXを使い、部品画像は `profile/ui/` に保存する。部品画像と校正情報は公開物に含めない。

---

## 前提条件と注意事項

- **解像度・DPI倍率・テーマ・言語が変わったら再校正。**
- **部品が読めなければ不足を伝えて停止する。**
- **他作品は操作しない。**
- **失敗を手でverifiedにしない。**
- 次の工程は [RUN.md](RUN.md) のrun。

## 手順 1. 準備と練習用ページの展開

### ユーザーまたはAIエージェントの操作
- **ユーザーへの依頼:**
  - GUI中はキーボードとマウスに触れないようユーザーへ伝える。
  - 前回の練習用タブが残っている場合は、ユーザーが閉じてから行う。
- **クリスタの準備:**
  - クリスタをメイン画面で最大化する（基準1920×1080・100%、複数画面なら主画面）。
- **コマンド実行:**
  - 空ページを持つCMCを指定して、プロジェクトルートで次のコマンドを実行する:
    ```bash
    autoclip.cmd setup prepare --cmc "input\作品\作品.cmc"
    ```
  - （再校正の場合）:
    ```bash
    autoclip.cmd setup prepare --recalibrate --cmc "…"
    ```

### 自動で行われる処理
- 先頭ページの練習用コピー `work/v2-setup/project/AC_setup_*.clip` が開く。
- `profile/ui/screen.png` が出力される。

## 手順 2. 部品画像の採取（crop）の基本原則

### ユーザーまたはAIエージェントの操作
- 出力された `profile/ui/screen.png` を必ず見て、元の画面ピクセル座標で部品を識別する。
- 部品の採取には次のコマンドを実行する:
  ```bash
  autoclip.cmd setup crop --name 部品名 --rect X1 Y1 X2 Y2 [--click-offset DX DY]
  ```
- **連続採取:** 同じ画面の部品は、画面を変えずに連続cropする。
- **注意:** 位置を推測しない。

### 自動で行われる処理（crop）
- 現在のscreen.pngを切り抜く処理であり、GUIは動かさない。

## 手順 3. 画面操作・ツール切替・メニュー操作

### ユーザーまたはAIエージェントの操作
- **ツール・チェックの切替:**
  - 次のコマンドを実行する:
    ```bash
    autoclip.cmd setup click X Y
    ```
- **メニュー操作（複数座標の一括指定）:**
  - メニューは途中の呼び出しで閉じるため、1回に複数座標を渡す:
    ```bash
    autoclip.cmd setup click X1 Y1 X2 Y2 X3 Y3
    ```
    *(例: ファイル→読み込み→画像)*
  - 座標は直前の観測画面で識別したものを使う。
- **画面の再確認と追加撮影:**
  - 操作後は、更新されたscreen.pngを見直す。
  - 追加撮影を行う場合は次のコマンドを実行する:
    ```bash
    autoclip.cmd setup shot NAME
    ```
    *(撮影名は英数字・下線・ハイフンで部品名以外)*

## 手順 4. ダイアログの採取

ダイアログは練習用ページから**開いてからcrop**する。採取後は**キャンセルで戻る**（採取時は保存・破棄しない）。戻った画面を見直す。

### ユーザーまたはAIエージェントの操作
- **「開く」ダイアログ / 「画像読み込み」ダイアログ:**
  1. それぞれタイトルをcrop採取する。
  2. キャンセルの座標をclickして練習用へ戻る。
- **保存確認ダイアログ:**
  1. 練習用に新規ラスターレイヤーを作る。
  2. 「閉じる」を実行してダイアログを表示する。
  3. タイトルと「保存しない」を同じ画面からcrop採取する。
  4. キャンセルで戻る。

## 手順 5. 採取対象の22部品一覧と仕様

下の22部品を採取する。

### 部品一覧表

| cropの名前 | 採取する部分 |
|---|---|
| frame_tool / frame_tool_on | コマ枠アイコンの未選択 / 選択状態 |
| frame_create | サブツールグループ「コマ作成」 |
| rectangle / polyline | 「長方形コマ」 / 「折れ線コマ」 |
| raster_on / raster_off | 「ラスターレイヤー」チェックのON / OFF（ラベルを含める） |
| fill_on / fill_off | 「コマの内側を塗りつぶす」チェックのON / OFF（ラベルを含める） |
| brush_size | ブラシサイズ欄。ラベルを目印にし、オフセットで入力欄を指す |
| file_menu / import_menu / image_menu | 「ファイル」 / 「読み込み」 / 「画像」 |
| top_folder | フォルダー行の安定した目印。オフセットで名前欄を指す |
| file_dialog / image_dialog | 「開く」 / 「画像読み込み」のダイアログタイトル |
| save_dialog / discard_button | 保存確認タイトル / 「保存しない」 |
| view_menu / fit_canvas | 「表示」 / 「画面に合わせる」 |
| view_top_left / view_bottom_right | 安定したUI目印とビュー左上 / 右下へのオフセット |

### 採取時の要件と確認事項
- **状態の網羅:** `frame_tool` と `frame_tool_on` の両状態が必要。
- **top_folder:** 名前変更でも変わらないフォルダーアイコンを目印にし、名前欄の中央へクリックオフセットを付ける。照合候補が複数なら最上段の一致を使う。
- **ツール設定の確認:**
  - 両コマツールの「追加方法＝フォルダーを新規作成」「枠線を描画＝ON」を画面で確認する。
  - ラスターレイヤーと内側塗りつぶしは実行時にOFFへ揃える。

## 手順 6. ビュー端（view_top_left / view_bottom_right）の特定

### ユーザーまたはAIエージェントの操作
- **特定ルール:** 用紙の端ではなくビュー領域の端を対象とする。
- **位置の制約:** `view_top_left` は画面の左上4分の1、`view_bottom_right` は右下4分の1の範囲だけから探す。範囲外の似た形（別パレットのスクロール矢印など）は採用されない。
- **小さな矢印だけを切り抜かない:** 周辺の枠線・境界を含めて切り抜く（目安は縦横とも24px以上）。小さい画像を採ると `setup crop` が注意を表示する。
- **目印の選定とオフセット計算:**
  - 用紙サイズや表示倍率を変えても動かない、ビュー周辺の安定したUI目印をcropする。
  - 中心 `(X1+X2)/2, (Y1+Y2)/2` から目標のビュー端までの差をDX/DYとする。
- **範囲の検証:** パレット・メニュー・ステータスを含まない表示領域になるよう、上下左右を画面で確かめる。

## 手順 7. 検証と合格判定（setup check）

### ユーザーまたはAIエージェントの操作
- ダイアログをすべてキャンセルで閉じる。
- 次のコマンドを実行する:
  ```bash
  autoclip.cmd setup check
  ```

### 自動で行われる検証処理
次の条件がすべて合格して初めてverifiedになる:
- 各部品の観測画像との相関 ≥ 0.9
- 各部品が観測画面の**離れた複数箇所に一致しない**（一致すると不合格。繰り返し表示される `top_folder` は除く）。不合格なら、周辺を含めて採り直す
- 現在画面の照合 ≥ 0.9（`discard_button` だけ ≥ 0.8）
- 用紙領域の縦横比が練習用ページの用紙寸法と合う（`setup check --tolerance small|medium|large|ignore`、既定 medium）
- 色見本の**1コマ作成→画像投入→保存→SQLite確認**にすべて合格
  - 保存ファイルでネイティブ枠数・名前・最上位階層・画像の子レイヤーを確認する。
  - ルートのMainIdは固定しない。

### 完了時の動作
- 合格時はクリスタが最小化される。

## Python・組み込み拡大環境の導入

Windows、CLIP STUDIO PAINT EX、Python 3.12以上とuvが必要。
解析・CLI用は `scripts/setup.ps1` で `.venv-tools` に導入する。
組み込み拡大を選んだ場合だけ `scripts/setup.ps1 -BuiltinUpscale` と
`autoclip.cmd fetch-model` を実行する（保存先は `models/`、変更は `--dest`）。
公式重みのSHA-256を確認してからsafetensorsへ変換する。
CPU環境の導入は `-BuiltinUpscale -CpuOnly`。runの推論指定はCUDAのため、
CPU推論をrunで選択する機能は現在ない。
externalは指定したPythonとモデルだけを使い、環境の探索・変更は行わない。
