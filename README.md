# AutoClip

AIなどで作った漫画ページ画像を、CLIP STUDIO PAINT EXの本物のコマ枠フォルダーへ移送します。

- コマ枠のみ、またはコマ画像付きで投入できます。
- 拡大は `none`（通常拡縮）、`builtin`（組み込み）、`external`（指定Python・モデル）から選べます。
- ページごとに処理し、失敗したページは復元・再試行して、続きから再開できます。
- 元画像の縦横比を保って基本枠を隙間なく埋めます（縦横比が違うと端が隠れます。`--fit stretch` で縦横別々に合わせる従来方式も選べます）。
- 新しい作業の初回は1ページ目だけ処理して止まる「試運転」で、配置を確認してから残りを処理します。用紙領域の縦横比が合わない場合は描画前に安全停止します。

## 初回校正・一括処理

プロジェクトルートで実行します。

```powershell
.\autoclip.cmd setup prepare --cmc "作品.cmc"
.\autoclip.cmd run "画像フォルダー" --cmc "作品.cmc" --job 作業名 --upscale none
```

## 要件・利用手順

- Windows、CLIP STUDIO PAINT EX、Python 3.12以上。
- 導入スクリプトはuvを使用します。
- AI拡大は対応モデルとCUDA環境を必要とします。

[AIエージェントの規則](AGENTS.md) / [導入・校正](docs/SETUP.md) / [実行・再開](docs/RUN.md)

- コマ外の内容は取り込みません。
- 実機未検証の環境があり、AI拡大・確認ダイアログ・用紙領域の縦横比検査・試運転の実機検証は未完了です。
